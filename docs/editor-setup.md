# Cocos Creator 3.8.8 setup (manual Editor qualification)

1. Install/open Cocos Creator **3.8.8** and select the apps/cocos folder as a project.
2. Let Editor import TypeScript files and create .meta files (commit them after verifying serialization). The TS project extends temp/tsconfig.cocos.json generated by Editor.
3. Create a 2D scene (e.g. Connect.scene) with Canvas, one Label for connection state, and two Buttons named Connect and Ping.
4. Attach scripts/ui/ConnectionPanel.ts to a Canvas child or other persistent UI node.
5. Assign the statusLabel field to the Label. Connect Button -> ConnectionPanel.onConnectClick; Ping Button -> ConnectionPanel.onPingClick.
6. Start the separately built CHttp development gateway on the same workstation (127.0.0.1:1780).
7. Preview in browser, click Connect -> 'ready' after server.hello; click Ping -> 'ready (pong received)'.

The scaffold does not ship unverified hand-authored .scene/.prefab data. Editor-based asset serialization and a packaged Web build are **not yet validated**. Browser preview on another device cannot reach a server bound to 127.0.0.1 on the developer PC; public/remote connectivity is deliberately out of scope until authentication and TLS are implemented.

Next product scenes are Login, Lobby, Room and Game, to be added with real event/snapshot contracts in M1/M2.

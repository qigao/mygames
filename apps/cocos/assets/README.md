# Cocos Assets

TypeScript sources live in scripts/. Open this project in Cocos Creator 3.8.8,
then create the first Canvas scene and bind ConnectionPanel as described in
../../../docs/editor-setup.md.

This scaffold intentionally does not ship unverified hand-authored serialized
.scene/.prefab data. The Editor generates matching .meta files during import.

No proprietary assets were copied from ddz_game or third-party games.

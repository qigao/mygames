# Cocos Assets

TypeScript sources live in scripts/. Open this project in Cocos Creator 3.8.8,
then create the scenes and bind the ConnectionPanel as described in
../../../../docs/editor-setup.md.

This scaffold deliberately does not ship hand-authored .scene/.prefab
serialization without verifying it in the matching Cocos Editor. The Editor
generates matching .meta files when importing the sources.

No assets were copied from ddz_game or third-party games.
